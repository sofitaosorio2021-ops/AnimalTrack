¿Cómo funciona AnimalTrack?

Cada animal posee una caravana con un identificador RFID. Cuando la vaca ingresa al comedero, el sistema reconoce su chip, registra su peso y procesa la información correspondiente.

Los datos quedan registrados en la plataforma para facilitar el monitoreo del ganado y detectar posibles anomalías.

Conocé el proyecto AnimalTrack.

🐄 AnimalTrack

AnimalTrack es un sistema inteligente de identificación, monitoreo y alimentación automatizada para ganado.

El sistema utiliza tecnología RFID para identificar individualmente a cada animal. Al ingresar al comedero, se registra su peso y se procesan sus datos para determinar la alimentación correspondiente.

La información se almacena en una página web donde el productor puede consultar el historial de cada animal, observar su evolución de peso y recibir alertas ante posibles anomalías.

🌱 Territorios Vivos

Este proyecto fue desarrollado para participar en las Olimpíadas de Robótica bajo la temática Territorios Vivos.
